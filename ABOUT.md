

# About

This app was created for doctoral students at the Department of Food Studies, Nutrition, and Dietetics.

The goal is to (unofficially) calculate doctoral completion timing based on your current progress and expected future prolongation.

It supports both an average prolongation model and a semester-specific model, with timeline and activity views.

**Created by:** Thomas Roosdorp, thomas.roosdorp@ikv.uu.se.

Source code and more information are available on [GitHub](https://github.com/thoroo/phd-forecast).

If you find a bug or have a feature request, please [open an issue](https://github.com/thoroo/phd-forecast/issues/new) in the GitHub repository.
